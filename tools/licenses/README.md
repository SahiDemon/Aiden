# Legacy third-party notices

`lego-LICENSE.txt` and `lego-CHANGELOG.md` preserve the notices that accompanied the Lego ACME utility previously unpacked into the repository root. These describe that third-party tool, not Aiden's own release history or authorship.

Lego executables and local certificate output are ignored by Git. Retain publisher notices when distributing third-party tools. These files do not assign a project-level license to Aiden.
