## Design Context

### Users
The owner uses Aiden's dashboard while managing voice-triggered computer and smart-home actions. Timers need to be legible at a glance and easy to cancel without creating stress.

### Brand Personality
Calm, precise, and dependable.

### Aesthetic Direction
A clean dark control surface with cool, quiet blue emphasis. Timers should read like an orderly schedule, not an emergency warning system.

### Design Principles
- Use plain-language action names rather than internal command identifiers.
- Let the countdown be the visual focal point.
- Reserve red for destructive choices and genuine failures.
- Prefer one clear surface and deliberate spacing over nested glass cards.
